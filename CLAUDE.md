Read [AGENTS.md](AGENTS.md) first: it has the setup procedure, the rules (never take keys in chat,
the person does the Cloudflare login, ask before anything paid or sent) and the map of the code.

```bash
npm run preview       # local app with fake providers, http://localhost:8787, password "preview"
npm run setup         # set up on the person's Cloudflare account (interactive)
```
